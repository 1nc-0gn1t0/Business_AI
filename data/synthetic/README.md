# Синтетические демонстрационные данные

`coffee-kazan-v1.json` — авторский фиксированный сценарий кофейни с условной
географической привязкой к Казани. Не измерения рынка, не предложение помещения.
Три независимых значения: условный поток 1800/день, аренда 90000 RUB/месяц,
сценарные покупки 90/день. Никаких случайных чисел во время запроса.

У каждого значения origin=synthetic, observed_at=null, generated_at, source_name,
revision, confidence=not_applicable и ограничения. Метод fixed-authored-scenario-v1.
Авторские данные Sab0tage опубликованы по CC0-1.0. Персональных данных нет.

Опубликованный набор не переписывать: новая revision/дата/файл, новый SHA.
Импорт, серверное отключение и явный выбор demo описаны в
[DATA_PROVIDERS.md](../../docs/DATA_PROVIDERS.md). Автоматического fallback нет.
