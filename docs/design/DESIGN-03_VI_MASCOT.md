## Концепция и границы

«Ви — ваш маленький помощник для больших бизнес-идей». Новая точка входа — банковская
демонстрационная сцена: сине-голубой hero, белый крупный заголовок, спокойная навигационная
композиция, объёмная иллюстрация справа, светлая нижняя секция и три круглых элемента.
Это независимый хакатонный концепт, не официальный продукт ВТБ.

Композиционный источник — именно пользовательский скриншот A (главная [vtb.ru](https://www.vtb.ru/)),
а не предположение о текущем живом сайте. Банковское фото, рекламный текст с обещанием
выплаты, карточка ВТБ, логотип и ресурсы сайта не включены в поставку. Их заменяет собственная
CSS-композиция из карточки идеи, сферы и мягких фигур; это не банковское предложение.
Верхние пункты и две обычные круглые иконки — декоративные span, не ссылки/кнопки.
Белая плашка представляет Ви, не притворяется неработающей банковской кнопкой.
Единственное рабочее действие landing — знакомство с Ви. Нет login/регистрации,
платежей, реальных банковских форм/API и внешних скрытых переходов.

## Ассеты: фактический результат

Использованы предоставленные B и C, оба1536×1024 RGBA. B — основной дизайн,
C — прозрачный лист эмоций. На C **22 подписанных состояния**, не20. Полоса из трёх
голов «Печатает / Обрабатывает» — один составной вариант. Полный список реальных
подписей сохранён в [provenance.json](../../apps/web/src/assets/vi/provenance.json).

Подготовлены14WebP, суммарно282476bytes. Аватар192×192 —5216bytes; greeting345×364
пропорционально уменьшен до327×345 —11040bytes. Остальные изображения216–255px
по ширине; для отображения44–64px хватает исходного разрешения для Retina.
Крупное приветствие использует доступное разрешение исходного фрагмента, не выдуманный upscale.

| Ключ ViEmotion | Источник и подпись | Назначение |
|---|---|---|
| avatar | B, круглый портрет | Кнопка56/50px |
| greeting | B, приветствующий Ви | Панель и первый вопрос |
| curious | C, Любопытство | Уточнение в чате |
| neutral | C, Нейтральное выражение | Восстановление/спокойное состояние |
| thinking | C, Размышление | Настоящий расчёт/подбор |
| working | C, Работа над ответом | Ожидание сообщения/экспорта |
| search | C, Поиск информации | Ожидание геоанализа |
| idea | C, Идея | Полученные финансовые сценарии |
| confident | C, Уверенность | Завершённое сопоставление потребностей |
| uncertain | C, Не уверен | Неполнота/устаревшие вводные |
| success | C, Поздравление / Успех | Готовый актуальный отчёт |
| error | C, Ошибка | Отказ операции |
| ready | C, Готово | Подготовлен в mapping; отдельный экран не добавлен |
| support | C, Поддержка | Подготовлен в mapping; отдельная анимация не добавлена |

Результат — прямоугольное извлечение исходных пикселей, пропорциональное уменьшение
аватара и WebP quality94. Новые лица не генерировались; другой AI/image model не запускался.
Пропорции/палитра исходника сохранены, RGB-компрессия WebP не является побитовой копией.
У прозрачных C сохранены исходные мягкие тени/свечение; агрессивный white-removal не
применялся, чтобы не повреждать белый корпус. Подписи и соседние персонажи исключены.
Лапки и три синих элемента сохранены. [Контактный лист результата](../qa/design-03/vi-asset-contact-sheet.png)
проверен визуально; это QA-превью ассетов, не скриншот приложения.

Manifest фиксирует SHA-256 источников B/C, crop[x0,y0,x1,y1], размер/bytes/SHA каждого WebP.
Для воспроизведения нужны исходные пользовательские файлы с указанными hashes:
Pillow `Image.open(source).crop(box)`, `thumbnail((edge,edge), LANCZOS)` для аватара,
`save(..., 'WEBP', quality=94, method=6)`. Полные исходные листы и браузерный скриншот
банка в frontend/Git не копировались. Pillow уже есть в окружении проекта; новая зависимость не добавлена.

Происхождение — пользовательские вложения, не сторонняя коллекция и не официальные
ассеты банка. Отдельная публичная лицензия/документ об авторстве не предоставлялись;
коммерческое использование и банковское брендирование требуют отдельной проверки прав.
Разрешение на использование в данном порученном демо не означает официального согласования ВТБ.

## Компоненты и маршрут

- `Vi.tsx`: единый typed mapping `ViEmotion → URL`, ViAvatar, ViStatus, ViFloatingButton,
  ViWelcomePanel. Декоративные картинки имеют alt=""/aria-hidden, размеры зарезервированы.
- `Landing.tsx`/`vi.css`: новая сцена, original CSS-art, безопасная адаптивная композиция.
- `App.tsx`: оболочка и lazy BusinessFlow. Предыдущий App перенесён в `BusinessFlow.tsx`;
  серверные handlers и guards сохранены. Backend и API-контракты не менялись.
- `/#business-ai` открывает прежний рабочий маршрут, `/#main-content` поддерживает skip-link.
  Hash описывает экран и не даёт разрешений/готовности анализа. URL не содержит токенов.
- Landing не создаёт guest session и не запрашивает API до входа. После «Начать с Ви»
  открывается прежний вопрос, затем consent/dialogue/confirmation/location/finance/bank/report.
- Возврат по wordmark на главную сохраняет mounted workspace: сессия, draft и текущие
  результаты не удаляются. Возврат через Ви продолжает проект. Скрытый consent dialog удаляется из native top-layer
без выдачи согласия: иначе Browser Back оставлял landing inert. Регрессия воспроизведена и
проверена на всех трёх размерах. Browser Back/Forward
  синхронизирует оболочку. Reload сохраняет прежние ограничения DESIGN-02:
  реальный профиль/история восстанавливаются API, расчёты выполняются заново.

## Панель и пузырёк

Колонка справа: реакция, сообщение, Ви. Первые два элемента декоративные.
Desktop60px/10px gap, mobile54px/9px; offsets учитывают env(safe-area-inset-*).
Ви на светлом круге с тонким голубым контуром и мягкой тенью; портрет крупнее полного
маленького персонажа. Tooltip «Познакомьтесь с Ви» появляется на hover и focus.
Touch не требует hover. Нет звука, неона и постоянной пульсации.

Панель открывается только по нажатию. Native dialog/showModal обеспечивает семантику,
модальный focus и клавиатурное ограничение. Есть aria-labelledby/haspopup/expanded,
крестик44px, Escape и закрытие по настоящему backdrop-click (не по клику внутри текста).
При закрытии сначала закрывается native modal, затем фокус возвращается на trigger;
обратный порядок воспроизведён тестом как дефект и исправлен. Кнопка «Начать с Ви»
открывает существующий BusinessFlow, не создаёт альтернативный бот.
Размер/scroll панели ограничены viewport, включая390×568. Проверка iPhone — по размеру
viewport/safe-area CSS, реальное Safari/iOS-устройство не заявляется проверенным.

## Связь эмоций с реальными операциями

| Состояние | Ви | Проверяемое основание |
|---|---|---|
| Первый вопрос/панель | greeting | Открыт интерфейс, запрос ещё не начат |
| История проекта загружается | neutral | Общий busy без messages POST |
| Ответ на сообщение ожидается | working | waitingForReply вокруг существующей messages операции, finally снимает флаг |
| Уточнение после ответа | curious | Есть пользовательская история, запрос завершён |
| Геоанализ | search | Реальный busy в analyze, после ответа исчезает |
| Финансовый запрос | thinking | Незавершённый calculate API |
| Финансы получены | idea | Есть актуальный FinanceResult, даже если сценарий отрицателен |
| Финансовые вводные изменены | uncertain | Dirty, переход к следующему шагу блокируется как прежде |
| Банковский подбор | thinking/uncertain/confident | Busy/недостающие поля/завершение сопоставления; не кредитное одобрение |
| Экспорт | working | Реальный запрос подготовки/получения файла |
| Отчёт актуален и подготовлен | success | prepared/current, context совпадает, нет busy/error |
| Отчёт устарел | uncertain | Старый prepared не выдаётся за текущий |
| Ошибка | error | Реальная ошибка; сохранены сообщение, correlation ID и retry |

Эмоции не управляются таймером или LLM. Положительная эмоция означает завершение
вычисления, не прибыльность/доступность кредита. Нет успеха отчёта только от перехода
на Summary. Начальный extraction_mode=rules до первого ответа не объявляется stub
во время настоящего ожидания Qwen; реальный stub по-прежнему явно подписан «не Qwen».

## Анимации, доступность и производительность

Собственные одноразовые появления hero0.55/0.7s и панели0.2s, hover/press0.18s,
плавный tooltip. Референс статичный: анимации не заявлены копией наблюдавшегося сайта.
Анимация использует translate отдельно от responsive scale: визуальная проверка нашла
и исправила их конфликт на мобильном. Reduced motion отключает эффекты/hover rotation.
Действующий индикатор ожидания чата работает только до завершения операции.

Keyboard/видимый focus/skip-link/dialog Escape/close/backdrop/focus-return проверены.
Зоны карты, поля финансов и composer не перекрываются: companion встроен в поток,
плавающие элементы существуют только на landing. Полный WCAG2.2AA аудит не проводился.

Первый экран загружает только растровый avatar5216bytes; остальные raster payloads
появляются при открытии панели/соответствующего состояния. Vite dev дополнительно
запрашивает небольшие JS URL-модули изображений — это не загрузка всех WebP.
Production: initial JS230.11kB/gzip72.42kB (DESIGN-02:307.63/gzip92.82),
lazy BusinessFlow85.47kB/gzip23.60, lazy map1111.61kB/gzip305.45, worker516.71kB.
MapLibre и CSS остаются отложенными; его chunk warning >500kB остаётся известным.
Новых библиотек/runtime services/внешних API нет. Это размеры сборки, не лабораторный LCP benchmark.
