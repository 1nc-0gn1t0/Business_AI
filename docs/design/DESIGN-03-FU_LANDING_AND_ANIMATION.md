## Композиция и права

В DESIGN-03 абстрактная CSS-карточка занимала рекламную область. Теперь справа —
крупный исходный Ви, слева — двухстрочный белый заголовок и белая овальная кнопка.
Шапка содержит собственное название Business AI, центральный переключатель-композицию
и декоративные значки справа. Навигация, две верхние круглые пиктограммы и миниатюры
не выдают себя за работающие банковские действия. Оба рабочих элемента — белая кнопка
«Познакомиться с Ви» и третий пузырёк — открывают одну и ту же панель Ви.

Перед вёрсткой измерен пользовательский скриншот A: 1919×1087px, область сайта
примерно y112–1032 (920px). Это приблизительные измерения растра, не размеры DOM ВТБ.

| Элемент | Референс A | Новая реализация |
| --- | --- | --- |
| Левый отступ | 140px / 7,3% | 7,3% desktop, 6% tablet, 24px mobile |
| Шапка | около 112px | 112 / 100 / 86px |
| Заголовок | начало около 14% высоты сайта, около 84px | после шапки и 25px; 58–88px desktop |

| Нижняя композиция | миниатюры слева, светлая скруглённая граница | 3 декоративные миниатюры, точки; радиус 44 / 32px |
| Правая колонка | 2 круглых элемента | 2 декоративных + Ви, 60 / 54px, safe-area |

Градиент: #103bfa → #145ffc → #22a5f6 → #79d0fa. Высота hero близка к viewport,
с ограничениями для короткого экрана. CSS-стаггер появления заголовка/персонажа/миниатюр
и пузырьков, короткий hover; размеры зарезервированы, анимации не меняют layout.

Это соответствие композиции, **не пиксельная копия**: другой заголовок, собственный
wordmark и исходный Ви вместо банковской фотографии. Фотография, логотип, рекламные
материалы, код и авторизация ВТБ не копировались. Статус остаётся одной строкой внизу:
«Business AI — независимый проект. Не официальный сервис ВТБ».

Источники A/B/C — изображения владельца из задания DESIGN-03. B/C и 22 подписи
зафиксированы в прежнем [provenance manifest](../../apps/web/src/assets/vi/provenance.json).
Публичная лицензия на них не предоставлена; пригодность для дальнейшего коммерческого
или официального банковского распространения требует отдельной проверки прав.

## Растровый PoC и архитектура движения

Проверены CSS whole-image motion, разбиение растра и кадры существующих эмоций.
Выбран гибрид: приветствие/аватар — исходные растровые слои внутри небольшого SVG;
остальные состояния — прежние WebP с ограниченными CSS-реакциями. Покадровая подмена
отсутствующего движения и новый 3D-персонаж не создавались. Новых библиотек/моделей нет.

`ViEmotion` определяет изображение; отдельный тип `ViMotion` — движение;
событие pointer/focus/open или фактическое состояние запроса определяет trigger.
`ViAvatar`/`ViStatus` и прежний typed mapping сохранены. `ViRig` позиционирует слои по
централизованному manifest. Пути не размножены по экранным компонентам.

Семь новых WebP: корпус, поднятая лапка, три пёрышка и два исходных глаза.
**66024 bytes** изображений плюс небольшой JSON; прежние 14 WebP **не изменены**.
Полные bounds/bytes/SHA-256 каждого слоя — в
[motion/provenance.json](../../apps/web/src/assets/vi/motion/provenance.json).
Источник B проверяется по SHA-256 до обработки; crop=(90,100,830,885), canvas740×785.

Подготовка: ручные маски контуров/слоёв, удаление связанного с границей белого фона,
очистка отдельных остатков и мягкий alpha-край, WebP quality94. Под извлечёнными глазами
восстановлен только градиент поверхности из соседних исходных пикселей. Сами глаза и
остальная мимика исходные. AI-дорисовки, скрытого тела или новых лапок нет.

```powershell
uv run --locked --project apps/api python scripts/prepare_vi_motion.py C:/path/to/original-B.png
uv run --locked --project apps/api ruff check scripts/prepare_vi_motion.py
uv run --locked --project apps/api ruff format --check scripts/prepare_vi_motion.py
```

Pillow — существующая зависимость проекта. Нужен именно первоначальный B с совпадающим
хешем; исходные вложения не копируются в Git. Исходная поднятая лапка сохранена:
PoC машет ею, но **не воспроизводит подъём из опущенного положения**. У запястья оставлено
перекрытие оригинального корпуса, амплитуда ограничена. На большом hero возможен тонкий
матовый контур исходного белого фона; это ограниченный 2D-растр, не полноценный 3D rig.

| Motion | Реальный trigger / поведение |
| --- | --- |
| greeting | hover/focus пузырька, открытие панели/чата: наклон корпуса до 1,8°, 3 маха отдельной лапки за 1,8s, мягкий отклик каждого пёрышка, моргание |
| idle | нейтральный аватар: дыхание 6s×2, редкое покачивание пёрышек 14s×3, моргание 10s×3; затем покой |
| thinking | только активный ответ: изображение «Работа над ответом»/«Размышление», 3,6s×2; при долгом запросе остаётся неподвижным, статус ожидания остаётся честным |
| searching | только активный geo-запрос: исходный Ви с лупой, 2,4s×2; результат без искусственной задержки |
| idea | завершённый расчёт: однократный кивок 0,9s, без обещания положительной прибыли |
| success | только подготовленный актуальный отчёт: один мягкий прыжок 1,2s до 7px |
| error | спокойный наклон 0,6s, прежний безопасный повтор/correlation ID |
| none | большой персонаж hero статичен |

Другие эмоции не получили независимого разбиения на части. Это намеренная граница PoC.
Нет per-frame JS, случайных эмоций или бесконечной пульсации. Короткие движения не
подменяют готовность сервера. При reduced motion все эти анимации статичны.

Исправлена воспроизведённая потеря первого click: смена ключа SVG при focus могла заменить
pointer target между событиями. Декоративный аватар теперь pointer-events:none, события
получает стабильная кнопка. Native dialog сохраняет Escape/backdrop/крестик/focus-return.

## Производительность и доступность

Первый экран использует только 7 общих слоёв, 66KB; приветственная панель повторно
использует их из cache. Остальные 14 URL не загружаются как изображения до нужной эмоции.
`?no-inline` исключает включение маленьких слоёв base64 в JS. Нельзя утверждать, что
по-прежнему загружается только прежний 5KB avatar: большой hero требует новый набор.

Production initial JS232,00KB/gzip73,27KB (DESIGN-03:230,11/72,42), CSS30,70/7,87KB.
Отложенный BusinessFlow85,52KB, MapLibre1111,61KB/gzip305,45KB и worker516,71KB сохранены.
Предупреждение большого map chunk остаётся; это измерения bundle, не LCP benchmark.
Transform/opacity/rotate/scale не требуют вычислений JS каждый кадр. Видео — QA-артефакты,
они не импортируются приложением.

Проверены 1440/768/390px, также прежний короткий mobile568px в Chromium. Safe-area,
touch targets54px, панель внутри viewport, отсутствие горизонтального overflow.
Плавающие элементы только на landing; на рабочих экранах Ви встроен в поток.
Keyboard/видимый focus/skip link/native dialog/aria/reduced motion сохранены;
декоративный SVG и изображения aria-hidden. Это не полный WCAG-аудит.
