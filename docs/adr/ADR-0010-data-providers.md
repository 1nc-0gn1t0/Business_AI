# ADR-0010: явные локальные DataProvider и независимый demo-режим

Принято для BA-014, 24.10.2026. Продолжает ADR-0003/0005/0006/0009,
сохраняет модульный монолит, API георейтинга, сети, финансов и банка.

DataProvider Protocol читает одинаковые типизированные IndicatorResult.
OSMProvider адаптирует существующие PostGIS snapshots без дублирования хранилища.
SyntheticProvider читает операторские JSONB snapshots в provider_datasets (0007).
GHSLProvider/LicensedProvider — честно unavailable до проверенного набора/договора.
Пользовательский путь не обращается к внешним источникам и не использует LLM.

Значение наследует MetricWithProvenance BA-003; DataOrigin enum единственный.
Nullable wrapper выражает пропуски без нулей; география/лицензия/качество
наследуются от dataset. В ответе запрещено неявное смешение origin/source/version.
Числовой float DTO не заменяет Decimal деньги BA-009.

Синтетика: фиксированный авторский сценарий, маркировка на каждом значении,
история/проверка SHA/revision/atomic import. Случайность во время запроса отсутствует.
Серверный флаг по умолчанию false + demo в каждом запросе, без общей mutable
настройки пользователя/процесса. Переключение UI убирает устаревший результат.

Альтернативы: наследование старого строго числового DTO с nullable value ломает
BA-003; авто-fallback скрывает отсутствие данных; общий toggle меняет чужие запросы;
новый микросервис и raster stack GHSL без проверенного набора не нужны.

Новые показатели пока читаются отдельно и не включены в scoring/финансы.
Так сохраняется воспроизводимость старых алгоритмов. Будущая интеграция признаков
потребует явного запроса/версии и правила смешения; рыночная валидация не выполнена.
Подробности и команды: [DATA_PROVIDERS.md](../DATA_PROVIDERS.md).
