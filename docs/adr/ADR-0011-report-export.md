# ADR-0011: неизменяемый аналитический снимок и PDF/JSON из одного источника

25.10.2026, BA-015. Модуль reporting внутри монолита; прежние расчёты и DTO сохранены.

Клиент передаёт исходные запросы/fingerprints, а не доверенные итоговые цифры.
Сервер проверяет владельца/профиль и реконструирует существующими сервисами.
ReportSnapshot фиксирует результаты/версии/provenance и сохраняется в PostgreSQL
вместе с SHA и готовым PDF. Два формата не рассчитываются независимо.

ReportLab (BSD) и встроенный DejaVu Sans с лицензией дают кириллицу/₽ без внешнего
браузера, GUI, платных PDF-сервисов или тайлов в production. Векторная схема зон
не требует сети. JSON хранит полный графический/метрический результат; PDF даёт
читаемую сводку, с явным указанием сокращённых списков. Invariant canvas и сохранение
bytes обеспечивают воспроизводимость; фактическая дата отдельно в документе.

User-owned маршруты используют существующий гостевой header, не share URL с токеном.
Экспорт не банк/lead; отдельное согласие на банковскую передачу не требуется.
Source/profile changes делают обычное скачивание outdated; историческое - только
явно. Demo disable нельзя обойти историческим скачиванием. История не удаляется.

Альтернативы: доверие результатам клиента допускает подделку; независимый PDF-запрос
может смешать версии; headless Chromium/новая очередь тяжелее для 16 GB; тайлы
добавляют сетевые/лицензионные зависимости. LLM-summary не нужен для проверяемых фактов.

Лимиты body/snapshot/PDF/pages/reports, owner lock и мягкие временные checkpoints
достаточны для локального MVP. Публичному пилоту нужны глобальные квоты/retention.
