# ADR-0008: отдельные согласия и локальный mock lead

Принято для BA-012, 23.10.2026. Продолжает ADR-0001 и ADR-0007.

Нет официальной интеграции ВТБ. Финальный шаг MVP должен показывать проверяемую
демонстрацию без передачи данных банку и без фиктивных статусов рассмотрения.

В модульном монолите FastAPI добавлены независимые consent decisions, LeadDraft,
LeadSubmission и AuditEvent в PostgreSQL (0005). Три цели не объединяются.
Маркетинг необязателен; запрошенный пользователем подбор отделён от рассылок,
которые не реализованы. Для записи чата нужен assistant; для действий заявки —
assistant + demo_lead. История и базовые расчёты остаются доступными.

Снимок подтверждённого профиля отделён от минимального allowlisted payload.
Правки полей заявки отмечаются как draft_user_input. Fingerprint связывает
подтверждение с составом и версией профиля; изменение профиля или согласия
требует обновления и подтверждения черновика. Каталог проверяется повторно.

Профиль, отзыв, confirm и submit используют общую блокировку conversation.
Receipt + submitted + audit коммитятся атомарно. Idempotency UUID и уникальность
draft_id предотвращают дубли. MockLeadAdapter реализует Protocol, только создаёт DTO;
HTTP-транспорта, bank URL, внешнего идентификатора и кредитного решения нет.
LLM не разрешает передачу. Новых зависимостей и инфраструктуры нет.

Тексты не юридически утверждены. Аккаунты, retention policy, WORM, правовая проверка
и банковский API остаются для согласованного пилота/BA-020.
Контракты и ограничения: [CONSENT_LEADS.md](../CONSENT_LEADS.md).
