# ADR-0005: географические proxy-метрики и сравнимая группа

Дата: 23.10.2026. BA-008, без смены архитектуры монолита/источников BA-006/BA-007.

Ранжирование выполняет детерминированный Python/PostGIS-модуль. Он повторяет
BA-007 по снимку подтверждённого профиля, считает известные POI в одинаковом
геодезическом радиусе и нормализует показатели внутри полностью покрытой группы.
LLM не участвует в вычислениях. API сохраняет DTO BA-007 и отдаёт оценки по ID.
Новые таблицы, провайдеры, библиотеки и сохранение AnalysisRun не нужны.

Отказ от сравнения обрезанных кругов выбран вместо экстраполяции counts на
неизвестную площадь: распределение POI неоднородно. Запас до границы bbox
проверяется geography с сегментированной границей; частичные counts — нижние
границы, score/rank=null. Минимум две покрытые зоны, единая группа для всех
активных критериев; полностью ненаблюдаемый активный сигнал блокирует баллы.
Не перенормировать веса при пропусках, не превращать отсутствие конкурентов
в доказательство привлекательности. Геометрическое покрытие не означает
полноту картирования; эта неопределённость остаётся явным ограничением.

По умолчанию равны веса транспортной близости, разнообразия инфраструктуры и
отраслевого окружения: нет верифицированного основания выбрать более сильный
приоритет. Конкуренты нейтральны; cluster/separation включаются явно как
непроверенные экспертные гипотезы. Точные weights/radius/categories/mode
фиксируются SHA256 эффективной политики поверх версий формул/настроек.
Простая min-max выбрана для прозрачности; баллы несопоставимы между группами.
Константа >0 → 0.5; все нули → нет наблюдаемого сигнала; ties → стабильный ID.

Альтернативы: абсолютные пороги требуют отсутствующей калибровки; отрицательный
вес конкурентов по умолчанию навязывает недоказанную гипотезу; LLM-оценки
невоспроизводимы; пешие catchments требуют дорожного графа BA-013. Мы не
добавляем фиктивные население/аренду/выручку. Бюджет/формат без этих данных
остаются missing/not evaluated, а не становятся вымышленными поправками.

Ограничения: bias картирования, coarse категории, дубли OSM, прямые дистанции,
представительная точка не все места зоны. Default weights не обучены/не
валидированы по прибыли. Экспертная полевая проверка — будущая работа.
Формулы, статусы, воспроизведение и реальные примеры — [ZONE_RANKING.md](../ZONE_RANKING.md).

GIS-примитивы: [ST_Distance](https://postgis.net/docs/ST_Distance.html),
[ST_DWithin](https://postgis.net/docs/ST_DWithin.html),
[ST_Segmentize](https://postgis.net/docs/ST_Segmentize.html).
